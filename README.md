# Chicken Soup 1

A beautifully styled recipe page for a bone broth chicken & lentil soup—an ayurvedic-persian fusion healing soup inspired by ash reshteh.

## For returning

This soup is meant for those returning from a long journey, cooked to wish them good health and ease their transition home.

## What's included

- **bone-broth-ash-1.html** — Styled recipe page with ingredients, methods, and footer
- **footer.jpg** — Hero image for the recipe

## How to view

Open `bone-broth-ash-1.html` in any web browser, or view it hosted at:
```
https://jennaros8.github.io/soup-1-recipe/bone-broth-ash-1.html
```

## Design

- Clean, modern recipe layout
- Light dreamy aesthetic with blue gradient background
- Organized ingredient sections (the base, the spice paste, to serve)
- 6-step method guide
- Responsive design

## How to use

1. Clone this repo or download the files
2. Open `bone-broth-ash-1.html` in your browser
3. Follow the recipe step-by-step
4. Enjoy your healing soup
